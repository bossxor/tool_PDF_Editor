# PDF Editor

Windows용 PDF 뷰어·편집기입니다. 문서 읽기부터 주석 작성, 페이지 정리까지 한 공간에서 작업할 수 있습니다. Electron + React + [MuPDF.js](https://mupdf.com/) 기반이며, 개인·사내·지인 사용을 목적으로 만들었습니다.

네이비·민트 테마와 Pretendard 글꼴을 적용했으며, 최근 문서 화면과 탭으로 여러 PDF를 관리합니다. 글꼴은 프로그램에 포함되어 별도 설치 없이 적용됩니다.

> 작업 대시보드: <https://bossxor.github.io/works-dashboard/>

## 다운로드

현재 버전은 **v0.1.4**입니다. [최신 릴리즈](https://github.com/bossxor/tool_PDF_Editor/releases/latest)에서 받을 수 있습니다.

- [설치 버전 다운로드](https://github.com/bossxor/tool_PDF_Editor/releases/download/v0.1.4/PDF.Editor.Setup.0.1.4.exe) — 설치·바로가기·PDF 연결 프로그램 등록
- [포터블 버전 다운로드](https://github.com/bossxor/tool_PDF_Editor/releases/download/v0.1.4/PDF.Editor.Portable.0.1.4.exe) — 설치 없이 실행
- [SHA-256 검증 파일](https://github.com/bossxor/tool_PDF_Editor/releases/download/v0.1.4/SHA256SUMS.txt)

기본 PDF 프로그램으로 사용할 때는 **설치 버전**을 사용하세요. 설치 후 Windows의 **설정 → 앱 → 기본 앱**에서 `.pdf`의 기본 프로그램으로 PDF Editor를 선택할 수 있습니다. 설치 프로그램은 연결 프로그램 후보를 등록하며 사용자가 지정한 기존 기본 앱을 강제로 덮어쓰지 않습니다. 업데이트는 열려 있는 PDF Editor 창을 모두 저장·종료한 후 설치 파일을 실행하세요. 포터블은 파일 연결과 바로가기를 자동 등록하지 않으며, 종료 후 실행 파일 교체로 업데이트합니다.

설치·제거 시 앱 실행 여부를 직접 조회하고, 실행 중이면 저장·종료를 요청합니다. 이 확인 경로에서 PowerShell·cmd·taskkill을 실행하거나 앱을 강제 종료하지 않습니다. 실행 중인 포터블도 이름이 같아 먼저 종료해야 합니다. 이전 제거 프로그램의 정확한 탐지 원인은 아직 확인하지 못했으며, 서명 인증서가 없어 새 파일도 서명되지 않았습니다. 차단이 계속되면 백신 예외 등록이나 감시 해제로 실행을 강행하지 말고 탐지명·파일 해시를 확보해 주세요. SHA-256은 무결성 확인용이며 코드 서명을 대신하지 않습니다.

## v0.1.4 변경 사항

- 상단바 통합: 기본 제목줄을 없애고 탭 줄이 제목줄을 겸하도록 변경. 창 버튼(최소화·최대화·닫기)이 같은 색으로 겹쳐 표시되고, 탭 줄의 빈 곳을 끌어 창을 움직일 수 있음
- 파일이 열려 있지 않은 시작 화면도 같은 상단 색과 창 이동 영역 적용

## v0.1.3 변경 사항

- **설치 버전과 포터블 버전을 함께 배포**하도록 복원: 설치 버전의 PDF 연결 등록·바로가기·제거 기능 유지
- 설치·제거의 앱 실행 확인을 직접 조회 방식으로 변경하고, 셸 실행·강제 종료 대신 사용자에게 저장·종료 요청
- v0.1.2의 확대·축소 성능 개선 유지
- 두 실행 파일과 SHA-256을 함께 생성하고 프로젝트 최상위 실행 파일도 갱신
- v0.1.2의 ZIP 단독 배포는 설치 버전의 대체로 사용하지 않음

## v0.1.2 변경 사항

- 문서별 작업 스레드에서 PDF 처리·PNG 압축 실행: 렌더링 중에도 메인 스레드 응답 유지
- 연속 확대·축소 요청을 120ms 대기 후 병합하고, 화면 안 페이지만 렌더링
- 페이지별 진행 중 요청을 하나로 제한하고 이전 배율의 응답은 화면에 적용하지 않음
- 화면 비트맵을 약 800만 픽셀·변 길이 8192px로 제한, 최대 32MiB·64개 PNG 캐시 및 편집·실행 취소 시 무효화
- 고배율에서는 비트맵을 늘려 표시하므로 선명도가 제한될 수 있음. PDF 좌표·저장 내용과 인쇄 해상도는 유지
- 확대·축소와 창 크기 변경 시 읽던 페이지 위치 유지, 텍스트 선택 영역의 반복 레이아웃 계산 감소
- 렌더링용 비트맵과 페이지 자원, 화면 이미지 URL 정리
- 기본 배포를 제거 프로그램이 필요 없는 일반 ZIP으로 전환하고 SHA-256 제공

측정 방법, 검증 범위와 백신 탐지 조사 한계는 [성능·배포 검증 기록](docs/performance-and-distribution.md)을 참고하세요.

## 기능

**보기**
- 여러 PDF를 탭으로 열기, 파일 끌어다 놓기, 파일 연결로 열기
- 텍스트 선택·복사, 검색(페이지 위 하이라이트), 목차, 썸네일
- 확대/축소, 폭·페이지 맞춤, 두 페이지씩 보기, 페이지 번호 입력 이동, 전체화면(F11)
- 암호가 걸린 PDF 열기, 인쇄, 시작 화면의 최근 파일, 지난번 탭 복원
- 기본은 읽기 전용 뷰어이며, 우측 상단 **편집** 버튼으로 편집 모드에 들어갑니다.
- 문서 헤더에서 검색을 열고, 상태 표시줄에서 현재 페이지와 읽기·편집 모드를 확인할 수 있습니다.

**편집**
- 형광펜·밑줄·취소선: 텍스트를 드래그해 선택하면 뜨는 툴바에서 적용하거나, 도구를 켠 채 연속으로 드래그
- 사각형·원·선·펜·텍스트 상자·메모, 테두리색·채우기색·두께·투명도 지정
- 도형 선택 후 이동, 크기 조절 핸들, 방향키 미세 이동, 복사·붙여넣기
- 텍스트 상자 글자색·크기·배경색·테두리색
- 실행 취소/다시 실행, 암호 설정·해제 저장

**페이지**
- 회전, 복제, 삭제, 드래그로 순서 변경
- 다른 PDF 삽입(병합), 페이지 범위를 새 PDF로 추출(분할)

## 단축키

| 키 | 동작 |
| --- | --- |
| Ctrl+O / Ctrl+S / Ctrl+Shift+S | 열기 / 저장 / 다른 이름으로 저장 |
| Ctrl+P | 인쇄 |
| Ctrl+F | 검색 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+W, Ctrl+Tab | 탭 닫기 / 탭 전환 |
| Ctrl+Shift+Tab | 이전 탭으로 전환 |
| Ctrl+마우스 휠 | 확대 / 축소 |
| F11 | 전체화면 |
| V R O L P X N | (편집 모드) 선택·사각형·원·선·펜·텍스트 상자·메모 |
| Delete, 방향키, Ctrl+C / Ctrl+V | (도형 선택 시) 삭제, 이동, 복사 / 붙여넣기 |

## 개발

```bash
npm install
npm run dev        # 개발 실행
npm run typecheck  # 타입 검사
npm run build      # 앱 빌드 (out/)
npm run test:ui    # 빌드 + 숨겨진 Electron 창에서 UI 회귀 검증
npm run test:engine # 빌드 + 실제 PDF 엔진·작업 스레드 회귀 검증
npm run test:app    # 실제 main/preload/renderer 통합 검증 (test:engine 실행 후)
npm run test:installer # 기존 설치본·레지스트리를 바꾸지 않는 설치/제거 실행 확인 검증 (dist 실행 후)
npm run dist       # 설치 EXE + 포터블 EXE + SHA-256 (dist/)
npm run dist:installer # 설치 EXE만 빌드
```

배포 빌드가 완료되면 프로젝트 최상위의 `PDF Editor Setup.exe`와 `PDF Editor.exe`도 최신 결과로 자동 갱신됩니다. `dist/`에는 `PDF.Editor.Setup.0.1.4.exe`, `PDF.Editor.Portable.0.1.4.exe`, `SHA256SUMS.txt`, `win-unpacked/`가 생성됩니다. 서명용 인증서가 준비된 경우 electron-builder의 공식 코드 서명 설정으로 서명할 수 있습니다.

UI 회귀 검증은 테스트 문서 데이터를 사용해 시작 화면, 글꼴 로드, Ctrl+O 열기, 페이지 이동, 창 크기 변경 시 화면 맞춤, 확대율 표시, 검색 버튼을 확인합니다. 화면 캡처는 `.verification/`에 저장됩니다.
